# Demo photos

Real photos for the Demo staging page's scenarios (api/_demoScenarios.js). Name each one after its scenario,
e.g. `HP-01.jpg` (`.jpeg` and `.png` work too), then run `npm run build:demo-photos` and commit
`api/_demoPhotos.js`. Any scenario without a photo here gets a labeled placeholder. Use only photos you're
allowed to share and that show no real people or real job sites' identifying details.
